# 思维工具：传导链条与十工具

**摘要：** 投资研究的思维工具箱：传导链条回答"怎么影响"，十个工具补它的五个缺陷（反馈、状态、价值分配、因果识别、预期差），最后合成六步工作流。与[《股市笔记》](/posts/econ-principles)分工：那篇讲五层框架，这篇讲做题工具；工具服务于框架各层，引用处会注明回哪层。

**怎么读：** §1 传导链条（必读）→ §2 十工具（查表）→ §3 优先级与互补 → §4 工作流 → §5 研究问题选择。

## 1. 传导链条

**一句话：传导链条回答的不是"A 和 B 有没有关系"，而是 A 通过什么环节、什么条件、多久、以何种失效方式影响 B。**

### 降息例

央行降息 → 融资成本下降（借钱变便宜）→ 投资消费可能增加（看借款意愿、信贷供给、需求预期）→ 盈利预期改善 → 估值可能上升（还看折现率与风险溢价）。它解释"可能通过哪些变量"，不断言"一定上涨"——企业无投资意愿、或降息因经济恶化而起，链条即断。

### 化工例（为什么必须看中间环节）

原油涨，化工股未必涨。路径 A：产品涨幅更大→价差扩大→利润增；路径 B：成本无法转嫁→利润降。判据是产品售价、价差、库存损益、下游承接、新增产能——链条把模糊判断变成一组可观测的中间变量。

### 五种类型

- **宏观链：** 降准 → 银行约束 → 信贷供给 → 融资支出 → 总需求（货币政策、信用周期）。
- **产业传导链：** 终端需求 → 订单 → 库存 → 利用率 → 价格利润（周期、利润池）。
- **定价链：** 实际利率 → 持有机会成本 → 配置估值 → 价格（利率汇率风险溢价）。
- **交易链：** 集中减仓 → 卖盘 → 深度不足 → 冲击放大 → 更多减仓（流动性、踩踏）。
- **技术商业链：** 推理成本降 → 应用可行 → 用量增 → 工作流变 → 收支与格局变（技术革命、商业模式）。

```mermaid
    A["初始变化<br/>发生了什么"] --> B["因果机制<br/>经什么环节"]
    B --> C["关键证据<br/>什么数据验证"]
    C --> D["必要条件<br/>缺什么即断"]
    D --> E["证伪条件<br/>什么出现即错"]
```

### 六检查（链条靠谱否）

起点（到底变了什么）、机制（为何影响下一环）、中间变量（可观测否）、必要条件、时间滞后（多久、会否提前反映）、失效条件。每加一环都要过六问，否则是故事不是链。

### 链与因果图的区别

链是单路径简化；因果图可表多因多果加反馈（如降息同时走估值、融资、预期、风险偏好四路，方向可相反，还受共同原因影响）。单判断都对、加总仍错，常因路径相抵或共同原因——这就是只画链不画图的代价。

### 分析模板（复制即用）

1. 初始变化：发生了什么？
2. 因果机制：通过什么环节影响结果？
3. 关键证据：哪些数据验证中间环节？
4. 必要条件：哪些条件必须成立？
5. 证伪条件：出现什么说明逻辑不成立？

## 2. 十个思维工具（查表）

**一句话：每个工具补传导链条的一个缺陷——反馈、状态、分配、识别、预期。**

- **反馈回路：** 结果反噬原因（涨→融资→扩张→再涨；或估值过高→成本升→反转）。解释泡沫、趋势、崩盘，线性外推失效处用它。
- **涌现与复杂适应：** 个体理性之和≠整体理性（齐减仓→深度没→冲击大→更多减）。市场是参与者互调的系统，会产出无人计划的结果。
- **状态转换：** 同变量异环境异效（低库存加需求涨价，高库存则无）。规律皆有适用状态，平均关系掩盖切换。
- **价值获取与议价权：** 谁创造谁拿走（客户/供应商/平台/渠道围着稀缺分钱）。从"看好行业"到"点出公司"的关键，对应利润池追问。
- **贝叶斯更新：** 新证据改多少判断（先验→似然→后验）。区分"听着重要"与"真改判断"。
- **预期差与反事实：** 价格反映的不是现实，是现实相对预期的变化（+20%遇+40%预期照跌）。把"世界怎样"和"市场如何定价"分开，对应反向估值。
- **混杂与因果识别：** 看到的关系真是它造成的吗（降息涨股也可能是共同预期改善）？找替代解释与共同原因。
- **期权思维：** 不确定 + 难收回投入时，等待、分阶段、小步试错比一次下注值钱（创业、技术路线、capex、职业通用）。
- **敏感性与脆弱性：** 结论依赖哪个假设、哪个变量一动就崩？区分稳健结论与单假设结论，尾部风险另算。
- **可证伪与样本外：** 什么证据算我错？事前写预测期限概率基准，事后对照；历史拟合好≠样本外有效。

## 3. 优先级与互补

**一句话：传导链条是地基，五个工具封顶——链条的五个缺陷各有一味药。**

| 优先级 | 工具 | 补链条的哪处漏 |
| --- | --- | --- |
| 1 | 预期差与反事实 | 解释企业价值，却忘价格已反映预期 |
| 2 | 反馈回路与复杂系统 | 只画单向，漏自我强化与反转 |
| 3 | 价值获取与议价权 | 停在行业，落不到公司 |
| 4 | 状态转换与非线性 | 假设机制恒成立 |
| 5 | 贝叶斯更新与因果识别 | 把合理解释当事实 |

## 4. 六步工作流（含例）

**一句话：变化→机制→反馈状态→分配→预期→检验，六步走完才算一篇研究。**

1. **识别变化：** 新信息还是旧事实？
2. **因果机制：** 经什么环节、可观测否？
3. **反馈与状态：** 自我强化？约束阈值？状态切换？
4. **价值分配：** 谁得益谁买单？议价权在哪？
5. **比较预期：** 市价隐含什么？新信息改了什么？
6. **更新检验：** 替代解释？什么证据推翻？

*例（AI 推理成本降）：* 降多少（硬件/压缩/降价）→ 用量增否 → 规模效应/供给约束/价格战 → 收益归芯片/云/模型/应用谁 → 估值隐含多高增长 → 订单/单位经济/毛利率/留存验证。

## 5. 研究问题选择（三层）

**一句话：不是所有可研究的问题都值得同等时间——按"理解世界/理解价值价格/验证自己"分层配时间。**

- **理解世界：** 因果机制、传导链条、反馈回路、复杂系统。
- **理解价值与价格：** 价值获取、状态转换、预期差、反事实。
- **验证自己：** 贝叶斯更新、因果识别、敏感性分析、可证伪性。
- **三问筛题：** 哪个变量真影响结果（重要性）？下条数据能否改决策（信息价值）？多花一周值否（机会成本）？
