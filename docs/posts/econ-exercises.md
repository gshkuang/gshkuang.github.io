## 题1 SOFR爆表：越上限就该跑吗？

**题干：** 自媒体称"SOFR突破上限，64%概率大跌，快清仓"。你查NY Fed仅单日越界，准备金仍在3.2T上，ON RRP未放量，2Y/10Y与TIPS无共振，过往同类越界几天即回落。请问单日越界能否当清仓信号？还差哪两个确认？

**考base哪节：** base §1.1/§1.2（短债周期）：美国看价，SOFR只是紧缩入口。

**解法：** 按观察+证伪走：①观测值（SOFR越界天数、准备金水平）；②核对口径（走廊定义与准备金统计口径）；③多解释（持续紧缩/单日扰动/技术因素）；④独立确认（ON RRP、2Y/10Y、TIPS是否共振）；⑤证伪条件见证伪线。旧稿演示阈值（如准备金约3.2T、单日胜率不足50%、"64%"说法），未经独立回测，仅作观察起点。

**证伪线：** SOFR回走廊内或准备金回升＋利差回落即作废；信号连两次命中<50%降权。

**仓位动作（风险预算框架）：** ①个人风险承受：按本人可承受回撤定；②组合占比上限自定：按个人投资政策定，不套统一百分比；③复核触发：SOFR回走廊或准备金回升即降仓/离场，比例按个人投资政策。单日越界不清仓、不加方向。

## 题2 期权Put倒挂：Put狂飙=风险近？

**题干：** 1121周五沪深300大跌你想割，但近月实值Call单日增仓超存量，PUT波动率下午下跳：标的更跌、PUT更便宜。另有文只看PCR飙升喊风险。请问真加多还是掩护？单看PCR够吗？

**考base哪节：** base §3.1（期权观察）：意图=ΔOI＋IV方向＋Skew。

**解法：** 按观察+证伪走：①观测值（Call ΔOI、PUT IV、Skew，注明合约/期限）；②核对口径（行权价、期限结构、做市对冲影响）；③多解释（真加多/掩护性对冲/到期换仓）；④独立确认（Skew＋期限结构＋IF基差共振，单看PCR为伪相关）；⑤证伪条件见证伪线。旧稿演示阈值（如ΔOI/OI约0.5、PUT IV下跳约10%、2/3分法），未经独立回测，仅作观察起点。

**证伪线：** 任两条反信号（PUT IV飙升/Skew扩大/Call增仓萎缩）即作废转防御。

**仓位动作（风险预算框架）：** ①个人风险承受：按本人可承受回撤定；②组合占比上限自定：按个人投资政策定，不套统一百分比；③复核触发：PUT IV飙升/Skew扩大/Call增仓萎缩等反信号出现即转防御，比例按个人投资政策。验证前只观察，不碰末日轮。

## 题3 13F转向：桥水减英伟达65%跟吗？

**题干：** 2025Q3的13F：桥水清仓黄金ETF、英伟达-65%、VV增持75%成第一重仓（5.78%→10.62%）。手持AI芯片跟不跟？怕卖在黎明前，又怕重演纳指-33%。滞后45天的作业该抄个股还是风格？

**考base哪节：** base §3.1（风格）＋§2.1/§2.5（定价）：13F定风格不定个股。

**解法：** 按观察+证伪走：①观测值（13F持仓变动、Top7集中度、保证金、信用利差，注明季末时点与45天滞后）；②核对口径（13F只含规则内多头、不含空头，非实时）；③多解释（风格切换/再平衡/个股基本面）；④独立确认（成长/价值比、历史相似阶段、利差方向多源共振）；⑤证伪条件见证伪线。旧稿演示阈值（如被动约10%、Top7约60%、保证金约8%、利差约3.25%、3分法、调整15-20%），未经独立回测，仅作观察起点；只定风格不定个股。

**证伪线：** Top7回55%下＋保证金转负＋利差回2.8%下即作废。

**仓位动作（风险预算框架）：** ①个人风险承受：按本人可承受回撤定；②组合占比上限自定：按个人投资政策定，不套统一百分比；③复核触发：拥挤回落＋保证金转负＋利差回落即重估，比例按个人投资政策。只抄风格不抄个股。

## 题4 老登vs科技＋李蓓卖飞：看对为啥没赚？

**题干：** 看对老登逻辑却减持银行、错过农行75%修复；认小微盘是火场它却新高；李蓓卖飞银行被嘲。请问逻辑错还是仓位错？卖飞何时是纪律？火场反弹返不返？

**考base哪节：** base §3.3（仓位/风险预算）：仓位=概率×赔率/波动容忍，看不懂零仓也是观点；中国先问量。

**解法：** 按观察+证伪走：①观测值（持仓集中度、拥挤信号如24-01三信号）；②核对口径（逻辑判断 vs 仓位结果分开复盘）；③多解释（逻辑错/仓位错/时机错）；④独立确认（府库配置、打孔机"不懂不碰"、股息/社融/M1多源）；⑤证伪条件见证伪线。旧稿演示阈值（如回撤8%、单票15%、现金20%）未经独立回测，仅作观察起点；看不懂零仓也是观点。

**证伪线：** 股息<3%且拥挤超90分位转现金；社融连2月>10%且M1转正切共振向上。

**仓位动作（风险预算框架）：** ①个人风险承受：按本人可承受回撤定；②组合占比上限自定：按个人投资政策定，不套统一百分比；③复核触发：股息与拥挤、社融与M1等证伪条件触发即切换，比例按个人投资政策。定投节奏按个人投资政策。

## 题5 本轮更像2000还是2008：先判定再谈抄底

**题干：** AI推高全球股市估值，自媒体一派喊"1929式大崩盘快跑"，一派喊"2008式抄底在即"。你查朱宁对照：1929是散户杠杆买股＋无watchdog＋无救助的十年Depression，2008是机构杠杆＋大救助的Recession，2000是无系统性债务违约的估值＋技术叙事杀。Mag6现35×（科网60×）、ERP 3.7%（顶部1%），关键见顶信号未现。请问抄底前先判定哪两件事？无救助能接飞刀吗？

**考base哪节：** base §1.2/§1.4（长债/去杠杆）＋§3.2（泡沫）：论泡沫先判定债务主体与救助有无。

**解法：** 按观察+证伪走：①观测值（债务主体类型、救助政策、估值位置如Mag6市盈率/ERP）；②核对口径（指数、起止日期、杠杆主体口径）；③多解释（2000式估值叙事杀/2008式杠杆传染/1929式长期萧条）；④独立确认（违约数据、救助规模、TIPS与科技走势背离）；⑤证伪条件见证伪线。估值数字为当时观察值非判定线；即使疑似泡沫亦不主动预言时点。

## 题6 紧缩期双主线：AI＋商品刚配＋Long/Short

**题干：** 美联储9-17加息25bp至3.75-4.00%，欧日韩跟进收紧，布油约100美元，10Y逼近5%，股债商三杀频发。你重仓纯多头Long Only科技成长，一年无收益还大波动。杨鑫斌称宽松结束转1-3年紧缩大周期：AI投资扩张＋地缘供应链冲击皆非加息可解，债券难对冲股票。请问纯多头还行吗？收益从哪来？组合怎么调？

**考base哪节：** base §1.1/§1.2＋§3.3：紧缩期先看分母杀估值（§2.2 ERP 四腿），降内部相关性而非赌方向。

**解法：** 按观察+证伪走：①观测值（核心PCE、SOFR方向、股债相关性、油价）；②核对口径（通胀来源：AI投资扩张/供应链冲击是否加息可解）；③多解释（短期冲击/1-3年紧缩范式）；④独立确认（股债相关转负、SOFR下行、核心PCE回落多源共振）；⑤证伪条件见证伪线。组合思路（AI＋商品、Long/Short、短久期）为观察框架下的配置讨论，非指令。

**证伪线：** 核心PCE回2.5%下＋SOFR下行＋股债相关转负即转Long Only；中东缓和致油价敞口失效即重配对冲腿。

**仓位动作（风险预算框架）：** ①个人风险承受：按本人可承受回撤定；②组合占比上限自定：按个人投资政策定，不套统一百分比；③复核触发：核心PCE回落＋SOFR下行＋股债相关转负即重估，比例按个人投资政策。事件窗前降仓安排按个人投资政策。

## 题7 医药黄金十年：四浪潮＋器械vs药价值曲线

**题干：** 医药连跌多年后 paycheck 式反弹，研报喊"黄金新十年"，让你追ADC/双抗/CAR-T小票。林伟框架：化疗→替尼→PD-1→ADC/双抗/CAR-T四浪潮，器械vs药价值曲线不同，药靠BD管线兑现、器械靠装机＋耗材，产业叙事再美也需现金流兑现。你手持无FCF纯叙事Biotech。请问追哪段？无FCF能追吗？

**考base哪节：** base §2.1（DCF 的双腿）：`P=FCF/(r-g)`；紧缩期**分母先动**（利率/ERP 上行，见 §2.2），分子决定能否修复；无 FCF 故事股先死。

**解法：** 按观察+证伪走：①观测值（浪潮位置/渗透率、BD与临床节点、装机与耗材、FCF与融资结构）；②核对口径（药 vs 器械价值曲线不同口径）；③多解释（真兑现/融资续命/情绪反弹）；④独立确认（FCF转正、BD到账、DFII10下行后股价是否仍跌）；⑤证伪条件见证伪线。旧稿演示数字（如云巨头capex可＋40%）未经独立回测，仅作观察起点；无FCF纯叙事先观察。

**证伪线：** 管线临床失败/BD停滞或FCF转负＋举债烧钱即作废；DFII10下行后仍跌即分子证伪非分母误伤。

**仓位动作（风险预算框架）：** ①个人风险承受：按本人可承受回撤定；②组合占比上限自定：按个人投资政策定，不套统一百分比；③复核触发：管线失败/BD停滞/FCF转负即离场，比例按个人投资政策。无FCF纯叙事只观察。

## 题9 量化全天候：风险平价＋先做存在性测试

**题干：** 股债商三杀下你的股债对冲失效，有人推"全天候"、有人让你抄量化因子。你查曹青青框架：全天候非预测复苏/繁荣/衰退/通缩，而是让风险在四象限可控，底层是名义GDP扩表＋风险平价；另有真假K线实验：真实K线与打乱伪K线可分才说明有模式，中频最拥挤最难分。请问策略上线前先做哪一步？拥挤市怎么办？

**考base哪节：** base §3.1/§3.3（结构）：先做存在性测试再谈策略，纪律清单vs认知笔记分离。

**解法：** 按观察+证伪走：①观测值（真假K线可分性、四象限风险贡献、股债商相关矩阵）；②核对口径（频率：日线/中频/高频可分性不同）；③多解释（真模式/过拟合/拥挤假象）；④独立确认（样本外表现、相关矩阵稳定性）；⑤证伪条件见证伪线。存在性测试（准确率是否显著超50%）先行，不通过不上线；恐慌三杀与基本面三杀区分处理。

**证伪线：** 真假难分（准确率≈50%）或相关矩阵突变致风险贡献失衡即停策略；三杀由恐慌转基本面（利差破3.5%＋保证金转负）即切防御。

**仓位动作（风险预算框架）：** ①个人风险承受：按本人可承受回撤定；②组合占比上限自定：按个人投资政策定，不套统一百分比；③复核触发：存在性不通过或相关矩阵突变即停策略，比例按个人投资政策。只做存在性通过的频率。

## 题10 半导体＋猪周期：库存高企与跌破成本能加仓吗？
