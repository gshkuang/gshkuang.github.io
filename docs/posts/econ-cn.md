# 中国市场案例包：A股的运行 / 定价 / 结构 / 证伪

> **用途：** 补 [《经济股市原理》](/posts/econ-principles) 的 A 股主场景缺口。正文 §5 案例以美股/西方市场为主，本篇按同一格式补 8 例中国案例；配套并行阅读 [《市场的多种逻辑》](/posts/econ-logics)（八种驱动逻辑）。
> **证据标准：** 与正文一致——每个数字须有**日期 + 口径 + 来源**。凡本包标“**待核**”的数字，是作者记忆中较可靠但**未逐条回溯原始发布机构**的值，引用前须回原文复核；标“**估算差异大**”的，不得当作精确值使用。
> **口径声明：** 指数涨跌均为**价格口径**（不含股息），除特别注明外；涨/跌幅为区间（峰值→谷值）或年度，非同一口径时分别标注。

读取方式：每例先写“运行层（宏观与信用发生了什么）”，再“定价层（谁在给边际定价）”，再“结构层（谁被迫买卖）”，最后“证伪层（什么观察会推翻它）”。四层缺一即降为观察。

## 案例 1｜2015 场外配资去杠杆（杠杆牛 → 强平踩踏）

- **运行层：** 2014–2015 年货币与信用环境偏松，"杠杆牛"由场内两融与场外配资共同推动；2015-06 起监管清理场外配资、收紧两融，事实性收紧资金供给（政策意图 ≠ 立即出清，但方向明确）。
- **定价层：** 估值与情绪双高，边际定价由杠杆资金主导——同一现金流预期，在杠杆资金退潮时会被更快重定价；属"流动性/微观结构"逻辑压过"现金流"逻辑。
- **结构层：** 配资盘触及平仓线 → 被动卖出 → 股价下行 → 更多账户触线，形成强平螺旋；叠加停牌潮使流动性进一步枯竭。
- **证伪层：** 若去杠杆是**温和渐进**（存量到期自然下降、无集中强平），则不应出现踩踏——事后看当时最大的误判是低估了场外杠杆的**规模与平仓机制的顺周期放大**。
- **关键观察与口径：** 上证综指 2015-06-12 高点约 5,178 → 2015-08-26 低点约 2,850，区间跌幅约 45%（上证综指收盘价，价格口径）；沪深两市两融余额 2015-06 峰值约 2.27 万亿元（交易所口径，**待核**）；**场外配资规模无权威统一数字（估算差异大），不引用精确值**。

## 案例 2｜2024 年 1–2 月 DMA/微盘流动性冲击（雪球敲入 + 杠杆平仓）

- **运行层：** 宏观无剧烈变化，冲击主要来自**市场微观结构**：雪球结构产品集中敲入、DMA（多空收益互换，常见 2–4 倍杠杆）与部分量化多头集中去杠杆，微盘/小市值持仓高度拥挤。
- **定价层：** 小市值此前由"壳价值 + 流动性溢价 + 量化抱团"定价；流动性收缩时，同一批标的被**打折抛售**，价格由流动性而非基本面决定。
- **结构层：** 微盘过度拥挤 → 触发线被击穿 → 被动平仓 → 流动性真空 → 微盘单日暴跌，形成与 2015 类似的顺周期螺旋，但主体从散户配资换成**机构化杠杆与衍生品**。
- **证伪层：** 若宽基指数不跟跌、全市场流动性未收缩，则只是风格切换而非系统性去杠杆——但 2024-01 各规模指数同步下跌，支持"流动性冲击"解释。
- **关键观察与口径：** 2024-01 沪深300 **-6.3%**、中证1000 **-18.7%**、中证2000 **-21.0%**（月度，价格口径，**待核**）；2024-02-05 万得微盘股指数单日约 **-13.7%**（Wind 口径，**待核**）；DMA 杠杆常见 2–4 倍（券商口径）。

## 案例 3｜2018 去杠杆与民企信用收缩（政策 → 信用 → 估值）

- **运行层：** 2018 年资管新规（2018-04）落地，表外融资收缩，社融增速快速回落，民企信用债违约上升——**"中国看量"**的典型：信用（数量）渠道收紧，先于价格渠道。
- **定价层：** 分子（盈利）下修与分母（风险溢价）扩张**同向叠加**；ERP 扩张是主导——即使无风险利率不高，风险溢价抬升也压估值（对应正文 §2.2 的第三条腿）。
- **结构层：** 高股权质押比例的民企面临平仓风险，形成"质押 → 下跌 → 补仓/平仓"的局部螺旋；资金向大盘蓝筹/国企集中。
- **证伪层：** 若信用扩张重启（社融同比回升、民企融资成本下行），则去杠杆叙事证伪——2018 年底至 2019 年初的社融企稳可作为对照。
- **关键观察与口径：** 上证综指 2018 全年约 **-24.6%**（收盘价，价格口径，**待核**）；社融存量同比由 2017 年末约 12%–13% 降至 2018 年末约 9.8%（央行口径，**待核**）。

## 案例 4｜2021 年白酒/核心资产抱团瓦解（拥挤度见顶）

- **运行层：** 2020–2021 年公募基金发行高峰，增量资金推动"核心资产"叙事；宏观利率并未剧烈上行。
- **定价层：** 高估值 + 长久期（DCF 终值占比高），**ERP 被压缩到低位**——一旦 ERP 转为扩张，即使利率不动，估值也承压（正文 §2.2 直接印证）。
- **结构层：** 拥挤度见顶 → 增量资金放缓 → 基金负反馈（净值下跌 → 赎回 → 被动卖出）→ 抱团拆解，是一个**微观结构 + 行为**驱动的过程。
- **证伪层：** 若盈利持续超预期且增量资金不断，抱团本可持续——事后看，拆解的触发是**拥挤度与资金流**而非单一基本面。
- **关键观察与口径：** 中证白酒指数 2021-02 高点至 2021 年 8 月低点区间的跌幅约 **-40%**（价格口径，**待核、约数**）；核心资产（茅指数类）同期亦显著回撤。**本案例只用"高点→低谷"区间描述，不引用单日精确值。**

## 案例 5｜2022 港股/中概（分母双杀：利率 + 风险溢价）

- **运行层：** 美联储 2022 年快速加息（分母端）叠加地缘、中概退市风险、地产信用收缩（风险溢价端），三重压力同向。
- **定价层：** 与美股 2022 同构但更极端——**实际利率上行（杀久期）+ ERP 扩张（杀风险资产）**双杀；成长/科技占比高的港股科技板块跌幅远大于价值板块。
- **结构层：** 外资流出、南向资金对冲、港币流动性受美元利率牵引；做空机制与流动性深度放大波动。
- **证伪层：** 若美元利率见顶回落 + 盈利企稳，则分母压力缓解、可反弹——2022 年 10–11 月与 2023 年初的反弹即分母逻辑的镜像。
- **关键观察与口径：** 恒生指数 2022 全年约 **-15%**；恒生科技指数 2022 全年跌幅更大（约 **-27%** 量级）；纳斯达克中国金龙指数 2022 跌幅显著（均为年度，价格口径，**待核、约数**）。

## 案例 6｜猪周期（产能周期 + 成本锚，微观供给侧）

- **运行层：** 猪价由**产能周期（能繁母猪存栏）**与短期压栏/二次育肥共同决定；效率提升（PSY）会拉长周期、压平弹性。
- **定价层：** 成本锚是核心——完全成本（约 11.5 元/kg，牧原口径）/优秀场线（约 10.5）/现金成本（约 10.16）三档决定"跌破到哪一档才触发去化"。价格跌破现金成本持续 → 被动去化。
- **结构层：** 上市猪企连续亏损现金流 → 被迫减产能/出清低效场；规模化提高但去化速度取决于融资能力与资产负债表。
- **证伪层：** 猪价站上成本线但**能繁不降反升**，或 PSY 再度跳升致成本中枢下移 → 右侧判断作废。
- **关键观察与口径：** 详细口径、三档成本与跟踪三数见素材《周期_猪周期牧原》与 `exercise_当前问题/正文_当前问题习题.md` 题 10/13（含首期跟踪小记，截至 2026-09-30）。**本包只做框架引用，不重复具体数值。**

## 案例 7｜地产链（政策 → 信用 → 盈利的慢传导）

- **运行层：** 2020-08 "三道红线"约束房企融资 → 2021 年起销售下滑 → 保交楼/融资支持陆续出台。政策意图（托底）与实际支出（销售、开工、拿地）之间存在**长时滞**。
- **定价层：** 地产链（开发/建材/家电/银行涉房）盈利预期下修 + 信用风险溢价抬升；与正文 §1.4 呼应——**名义增速 > 名义利率**并非充分条件，缺"本币计债 + 央行控利率 + 通胀预期锚定"任一前提即退化。
- **结构层：** 高杠杆房企信用事件 → 产业链需求塌陷 → 地方财政（土地出让金）承压，形成跨部门传导。
- **证伪层：** 若新房销售与拿地企稳、房企融资恢复，则链条修复假设成立；只看到"政策出台"不看到"销售/开工回升"不能算兑现。
- **关键观察与口径：** 新房销售面积由 2021 年峰值约 17.9 亿平方米回落（统计局口径，**待核、约数**）；本包不做精确外推。

## 案例 8｜红利拥挤（低利率 + 资金抱团，与成长风格跷跷板）

- **运行层：** 2023–2024 年利率下行 + 经济增长放缓 → 高股息资产的相对吸引（低估值 + 稳定分红）上升。
- **定价层：** 红利定价 = 稳定分子（分红）+ 低估值分母；但**拥挤度上升**后，红利也会从"低估值"变成"抱团资产"。
- **结构层：** 资金向银行/煤炭/电力/运营商等集中，红利拥挤度成为新的风险指标；成长风格回暖时资金回流，红利相对跑输（跷跷板）。
- **证伪层：** 利率回升或成长风格回归 → 红利相对收益走弱；分红削减或行业集中度过高 → 逻辑受损。
- **关键观察与口径：** 红利择时与拥挤度口径见素材《红利_红利风格择时与拥挤度_国泰海通》《红利_高股息策略长期有效性_东财中证红利》。**本包只做框架引用。**
